# BiteOscope_human_pathogen

Repository for the study "Deep behavioral phenotyping of pathogen infected
mosquitoes reveals species-specific behavior changes enhancing transmission"

The repository contains the code for DeepLabCut-assisted pose estimation, the individual-level mosquito
behavioral statistics and the transmission model. The behavioural classification
tool itself is a separate repository that can be found at: https://github.com/RUMCvectorBiology/

## Layout

    BiteOscope_analysis/          pose estimation and individual level mosquito statistics,
                                  see BiteOscope_analysis/README.md
    MBITES/                       transmission model, 
                                  see MBITES/README.md

## Settings

  - The analysis pipeline, dependencies and settings are described in
    BiteOscope_analysis/README.md.
  - The transmission-model code and its settings are described in
    MBITES/README.md.
